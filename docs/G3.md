## What was written

| Area | Where | Notes |
|---|---|---|
| Server | `studio/src/server.ts` | Bun, no dependencies, 127.0.0.1 only. Serves the page, proxies the 8 dev bridge commands, watches Studio files and pushes changes over server-sent events, holds what the person sees, relays agent notices. |
| Security | `studio/src/guard.ts`, `studio/src/discovery.ts` | Token in the page and in `~/.ukiyo/studio/<pid>.json` (0600); Host check against DNS rebinding; same-origin JSON writes; CSP `script-src 'self'`. |
| Files as UI | `studio/src/manifest.ts`, `panels/`, `layouts/`, `themes/`, `studio.json` | Panels auto-discovered by file name; layouts are CSS grid areas validated for rectangles and track counts; themes must define every token; composition written atomically. |
| Shell | `studio/web/` | Plain ES modules. Polls status at 4 Hz (1 Hz in a hidden tab), snapshots when the tick moves, remounts only changed panels, applies the cached theme before first paint. |
| Panels | `studio/panels/` | transport, viewport (GPU frame, watch, play passthrough), values, entities (selection shared with agents), sessions, input (record → input script), log, composer. |
| Agent side | `tools/mcp/src/tools/studio.ts` (`ukiyo_studio`), `tools/mcp/src/bridge.ts` (shared bridge client), `skills/ukiyo-studio` | view, notify, compose, list, check. |
| Engine skills | `skills/ukiyo-engine`, `ukiyo-renderer-dev`, `ukiyo-platform-dev`, `ukiyo-tooling`; `engine` preset; linked into `.claude/skills` and `.agents/skills` | For agents working on ukiyo itself. |
| Tests | `studio/test/studio.test.ts`, `tests/Ukiyo.Tests/DevBridgeTests.cs` | File validation, composition writes, request guard; dev bridge token, status, step, errors over a real loopback socket. Never run. |

## Checks that close the Studio base

```sh
(cd studio && bun test)
(cd tools/mcp && bun test)
dotnet test tests/Ukiyo.Tests --filter DevBridgeTests
dotnet run --project samples/LanternRun/Desktop &
bun studio/src/server.ts      # open the printed URL
```

In the browser, at 1440 and 390 px wide, in both themes:

1. The page connects to LanternRun within 2 s; tick advances; Pause holds it; +1/+10/+60 step exactly.
2. Capture shows the Metal frame; Watch updates it while running and stops capturing while paused.
3. Play: arrow keys and Space move the lantern; Tab leaves the frame and releases held keys.
4. Record → play → Stop gives a script; `ukiyo_run` with that script reproduces the same snapshot.
5. Editing `studio/themes/ink.json`, `studio/layouts/balanced.json` and `studio/panels/values.js` updates the open page
   without a reload. An invalid layout, theme or `studio.json` shows the file error and keeps the last valid UI; a
   panel whose module fails to load shows its error in place and in `ukiyo_studio view` → `panelErrors`.
6. `ukiyo_studio view` reports the focused panel and selected entity; `ukiyo_studio notify` shows a notice.
7. A request from another origin or without the token is refused (401/403/421).

Record results here with dates, browser and versions. Anything that fails is listed as failing.
