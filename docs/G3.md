# G3 · Studio — status

**State: base runs against a live game.** Watch, pointer passthrough and downloaded-recording replay now have live Metal evidence (2026-10-13, below).
G3 also includes controlled reload (not started). The existing dev bridge now has an editor-neutral CLI adapter.

### Automated recording → replay coverage

`DevBridgeTests.Bridge_recording_replays_LanternRun_state_sound_and_pixels_headless` now exercises
`record`, `input` and `step` through a real loopback TCP connection, then feeds the returned JSON script into a
fresh LanternRun runtime without a window. Both cases pass: recording after one idle title tick and after 61.
The tests check absolute event ticks (including two events in one tick), actual gameplay progress, the complete
snapshot, sound events and byte-identical CPU-rendered PNG captures. The full C# suite passes: **82/82**.

This verifies the bridge-to-runtime path, not the Studio's browser buttons, downloaded file or Metal readback.
The Record → Save → headless CLI check is covered by the later live run below. Reproduction requires the same initial game state,
viewport and preceding input history; starting a recording midway through arbitrary gameplay does not save that
state, and shifting the recorded ticks to zero would not restore it.

### Frame panel browser regressions

`bun studio/test/viewport.browser.ts` runs the actual Frame panel in headless Chrome with a controlled bridge
test double. It requires Playwright available locally and installed Chrome (`UKIYO_BROWSER_CHANNEL` overrides
the browser channel); it does not download a browser or add a production dependency.

Verified: a failed Watch capture retries at the same tick, a successful paused capture is not repeated, dragging
outside the image releases the pointer at outside coordinates (not the last inside location), pointer cancellation
releases once, and Tab releases held keys. No page errors. Studio unit tests: **20/20**.

The initial browser regression failed on the missing retry. The panel now records only successful capture ticks,
invalidates old Watch loops on toggles/session changes/unmount, forwards pointer movement, captures pointer drags,
and releases held input on blur, cancellation, Play off and unmount. Cancellation releases outside the drawing buffer
so it cannot accidentally activate a game UI button. This fixture is not Metal or full Studio-server evidence;
the separate live run below covers those boundaries.

### Editor-neutral CLI · 2026-10-13

`bun tools/mcp/src/cli.ts live --help` exposes discovery and all bridge commands without MCP or Studio (eight at the
time; a ninth, `patch`, submits one scene patch: `live patch --pid N --patch FILE`, see docs/scenes-patches.md).
It produces JSON stdout, stderr diagnostics and exit 1 on errors; multiple sessions require an explicit PID.
`--out` exclusively creates a PNG for capture, a script array for recording, or JSON for other commands.
See `skills/ukiyo-live/SKILL.md` for editor-task examples. No editor-specific extension or hot reload is implied.

Live Metal smoke: discovery, pause at tick 1349, step 10 to tick 1359, 1920×1280 PNG capture, record on/off and
script export all passed. The shared bridge client now rejects an incomplete socket response on disconnect rather
than waiting 30 seconds; real-loopback tests cover disconnect and a response split across writes.
