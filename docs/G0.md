## What was built

- `Ukiyo.Render` — renderer contract (`IRenderer`, optional `IRenderCapture`), generational handles, validation,
  binary protocol v1 (`docs/protocol.md`), PNG encoder.
- `Ukiyo.Core` — fixed 60 Hz clock with counted catch-up drops, `IGame`, `GameRuntime`, source identity, snapshots.
- `Ukiyo.Render.Null`, `Ukiyo.Render.Wgpu` (hand-written AOT-safe bindings for the pinned wgpu-native headers,
  WGSL pipeline, depth, resize, GPU readback capture), `Ukiyo.Render.Three` (C# facade over `[JSImport]`).
- Hosts: `Ukiyo.Platform.Headless`, `.Desktop` (SDL3 + CAMetalLayer, everything on the main thread),
  `.Browser` (single frame coordinator: `requestAnimationFrame` only forwards time to C#).
- `web/three-adapter` — persistent handle → geometry/material maps, applies packets, no game logic.

## Pending (not blocking the local gate)

1. **Clean machine.** The single binary has not run on a Mac without a .NET SDK anywhere on disk; this Mac has one in `~/.dotnet`. NativeAOT does not load it, but the plan asks for a clean environment before certifying.
2. **WebGPU path.** The browser path uses `WebGLRenderer` (WebGL2) and the automated evidence runs in headless Chrome on SwiftShader. Three's WebGPU renderer and a real-GPU browser capture are not validated yet.

## Known limits and honest notes

- The desktop capture re-renders the last packet into an offscreen texture with the same pipeline and reads it back; it is not a readback of the swapchain image itself.
- Startup frames while the window is still occluded are skipped and counted (`skipped=` in the log), never hidden.
- Desktop resize is exercised programmatically (`SDL_SetWindowSize`), not by dragging.
- JS→C# error translation (`[RENDER:Code]` → `RenderException`) is implemented; only the decoder side has automated tests, not a live browser round trip.
- One full `scripts/g0.sh` run stopped at the web AOT step without a recorded error; two later full runs passed. Not reproduced.
- Pinned toolchain: .NET SDK 10.0.401 (runtime 10.0.12), wgpu-native v29.0.1.1, SDL 3.4.16 (built for macOS 12.0), three 0.186.0 (newest release older than the 7-day minimum release age in the local bun config), Emscripten 3.1.56 from the `wasm-tools` workload.
